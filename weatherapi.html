Weather API App

JavaScript · REST API Case Study

A responsive weather application that fetches live data from a public weather API. Users search by city and receive current conditions, temperature and basic forecasts — strengthening async JavaScript, API integration and error handling skills.

Project Overview

The goal was to move beyond static UI clones and practise consuming real external data. The app accepts a city name, calls a weather API, and renders the response in a clear, mobile-friendly interface.

This project demonstrates practical use of fetch, async/await, handling loading and error states, and presenting API data in a user-friendly way — skills that transfer directly to full-stack and front-end roles.

Tech stack

HTML5 CSS3 JavaScript REST API Fetch / Async

Problem addressed

Many junior portfolios only show static pages. Integrating a live API proves the ability to work with real-world data, handle network failures, and build interactive experiences.

Key Features

City Search

Search weather by city name with instant feedback

Live Conditions

Temperature, description and basic metrics from the API

Loading States

Clear loading and error messages for better UX

Responsive UI

Works smoothly on desktop and mobile devices

What I Learned

  • How to structure async JavaScript with fetch and async/await for API calls
  • Handling loading, success and error states so the UI stays clear and trustworthy
  • Parsing and displaying JSON data in a readable, user-friendly layout
  • Importance of input validation and graceful failure when an API request fails
  • Connecting front-end skills to real external services — a step toward full-stack work
