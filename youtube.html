Front-End Development Project

YouTube Clone

A responsive YouTube homepage clone developed using HTML, CSS and JavaScript. This project recreates the familiar YouTube interface while demonstrating responsive layouts, reusable components and interactive front-end functionality.

Live Demo GitHub Repository

Project Overview

The objective of this project was to recreate the YouTube homepage using modern front-end development technologies. The focus was on producing a responsive, visually appealing interface while applying best practices in HTML, CSS and JavaScript.

During development I concentrated on creating reusable layouts, improving responsive behaviour, organising components efficiently and enhancing the overall user experience through clean interface design.

Recreate YouTube's homepage using semantic HTML, modern CSS and JavaScript.

Build a responsive interface that adapts to desktop, tablet and mobile devices.

Key Features

Video Grid

Created a responsive grid layout displaying video thumbnails, titles, channels, views and upload dates.

Sidebar Navigation

Built a collapsible sidebar with navigation links similar to the official YouTube interface.

Search Bar

Designed a fully responsive search interface with interactive styling and hover effects.

Responsive Layout

Implemented responsive layouts using CSS Grid, Flexbox and media queries for different devices.

Video Cards

Created reusable video card components for easier maintenance and scalability.

Modern UI

Applied clean typography, spacing and colour hierarchy to improve readability and user experience.

Design Decisions

  • Used YouTube's familiar navigation layout to provide an intuitive browsing experience.
  • Designed reusable components to simplify future development and maintenance.
  • Focused on spacing, alignment and visual hierarchy to improve readability.
  • Used CSS Grid for the video gallery and Flexbox for navigation and header alignment.
  • Optimised the interface for multiple screen sizes through responsive media queries.

Development Process

  • Analysed the YouTube homepage to understand its structure and layout.
  • Created the page structure using semantic HTML.
  • Styled the application using CSS Grid, Flexbox, transitions and animations.
  • Added JavaScript to improve navigation and user interaction.
  • Tested the interface on desktop, tablet and mobile devices.
  • Refined responsiveness, accessibility and overall performance before deployment.

Accessibility & Responsive Design

Accessibility

Used semantic HTML, descriptive alt text, logical heading structure and keyboard-friendly navigation to improve accessibility.

Responsive Design

Built using a mobile-first approach with responsive breakpoints to provide an optimal experience across all devices.

Performance

Optimised layouts, reusable components and image sizing to improve loading speed and maintainability.

Challenges & Solutions

Responsive Video Grid

One of the biggest challenges was recreating YouTube's responsive video grid while ensuring consistent spacing and alignment across desktop, tablet and mobile devices. CSS Grid and media queries were used to solve this challenge.

Navigation Layout

Creating a responsive sidebar that behaves like YouTube's navigation required careful planning using Flexbox, transitions and responsive breakpoints.

Reusable Components

Video cards were designed as reusable components, making the code easier to maintain and allowing additional content to be added with minimal effort.
