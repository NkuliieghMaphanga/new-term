Project Simulation • Solo Project

Twitter (X) Timeline Clone

A fully responsive Twitter/X timeline clone developed with HTML, CSS and JavaScript. The project recreates the look and feel of Twitter's home feed while demonstrating responsive design, modern UI principles and interactive front-end functionality.

Live Demo GitHub Repository

Project Overview

This project was completed as part of the Zaio Full Stack Web Development Programme. The objective was to recreate Twitter's homepage while applying modern front-end development principles, responsive layouts, JavaScript interactivity and clean UI design.

Beyond recreating the interface, I focused on writing reusable code, creating smooth user interactions and improving accessibility. The project also challenged me to think like a front-end developer by balancing design, usability and functionality.

Key Features

Dark Mode

Added a dark mode toggle with Local Storage to preserve the user's theme preference.

Who to Follow

Responsive Navigation

Implemented a mobile-friendly navigation menu for smaller devices.

Design Decisions

  • Used Twitter's familiar three-column layout to improve usability and user recognition.
  • Selected a dark colour palette with blue accents to maintain consistency with my portfolio while reflecting Twitter's modern interface.
  • Prioritised readability through clear typography, generous spacing and accessible contrast.
  • Designed reusable cards and components to simplify future maintenance and scalability.
  • Applied responsive design principles to ensure a consistent experience across different devices.

Development Process

  • Analysed Twitter's interface and identified its core layout and functionality.
  • Created semantic HTML to establish the page structure.
  • Styled the interface using CSS Grid, Flexbox and responsive media queries.
  • Implemented JavaScript to add tweet creation, theme switching and interactive behaviour.
  • Tested responsiveness across desktop, tablet and mobile screen sizes.
  • Refined the interface through debugging and usability improvements.

Challenges & Solutions

Responsive Layout

Recreating Twitter's three-column layout across desktop, tablet and mobile devices required careful use of CSS Grid, Flexbox and media queries.

JavaScript Logic

Managing tweet creation and updating the timeline dynamically strengthened my understanding of DOM manipulation and event handling.

Dark Mode

Implemented a theme toggle with Local Storage so the user's preferred theme remains active after refreshing the page.

Results & Achievements

  • Built a responsive layout for desktop, tablet and mobile devices.
  • Implemented interactive JavaScript features including dynamic tweets and dark mode.

  • Strengthened problem-solving and front-end development skills.

This project also improved my confidence in debugging, testing and building scalable web applications.
