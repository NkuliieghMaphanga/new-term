HTML & CSS Project

UI Screenshot Clone

A pixel-perfect recreation of a provided user interface screenshot using only HTML5 and CSS3. The project focused on layout accuracy, responsive design, accessibility, semantic HTML and modern CSS techniques without using any frameworks.

Live Demo GitHub Repository

Project Overview

This project required recreating an existing UI screenshot as accurately as possible using only HTML and CSS. The objective was to improve attention to detail while strengthening responsive design skills and developing reusable styling techniques.

The interface was built without Bootstrap, Tailwind CSS or any front-end frameworks. Everything was coded manually to demonstrate a strong understanding of layout, positioning, spacing, typography and colour management.

Assignment Requirements

  • Recreate the provided screenshot using only HTML and CSS.
  • Do not use Bootstrap, Tailwind CSS or any other CSS framework.
  • Implement at least three CSS custom properties (variables) for colours, spacing or typography.
  • Ensure the design passes a basic accessibility colour contrast test using the WebAIM Contrast Checker.
  • Deploy the finished project using Netlify or GitHub Pages.
